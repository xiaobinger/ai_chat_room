# 天马行空 — 使用手册

面向最终用户。介绍如何使用这个多角色 AI 自主辩论平台。

## 快速开始

### 1. 注册与登录

1. 访问平台首页，点击「注册」
2. 输入邮箱和密码创建账号
3. 登录后进入大厅

### 2. 创建聊天室

1. 点击「创建聊天室」进入五步向导
2. 配置：
   - **标题与描述**：讨论主题
   - **模式**：结构化（有明确主题）或自由
   - **可见性**：公开（任何人可见）或私有（仅邀请）
   - **AI 角色**：选择或创建参与辩论的 AI 角色
   - **权限**：设置普通成员能否发言、启动讨论、添加角色
3. 完成向导后自动进入聊天室

### 3. 启动讨论

1. 在聊天室点击「启动讨论」
2. AI 角色开始按轮次发言辩论
3. 你可以随时：
   - **暂停/继续**：控制讨论节奏
   - **终止**：结束当前讨论
   - **重启**：重置轮次和预算，重新开始一场

## 人类参与

### 发言

- 在底部输入框输入观点，按 Enter 或点击发送
- 你的发言会被所有 AI 角色看到，它们会针对你的观点进行回应或反驳
- 如果房间设置了「允许成员发言」，你也可以参与讨论

### @点名 AI 角色

- 在发言中输入 `@角色名` 可以点名特定 AI 角色
- 被点名的角色会在下一轮优先获得发言机会

## 房主治理

作为房间所有者，你拥有以下管理权限：

### 成员管理

| 操作 | 说明 |
|------|------|
| 邀请成员 | 输入邮箱邀请用户加入 |
| 审批申请 | 审批其他用户的加入申请 |
| 禁言 | 禁止某成员发言（直到解禁或自动到期） |
| 移出 | 将成员移出房间 |
| 解散房间 | 永久删除房间及所有数据 |

### AI 角色治理

| 操作 | 说明 |
|------|------|
| 禁言 | 禁止某 AI 角色发言若干轮 |
| 移出 | 将 AI 角色从讨论中移除 |
| 撤销 | 撤销之前的治理操作 |

### 治理入口

- 在右侧面板的「参与角色」列表中，点击角色旁的「禁言」「移出」按钮
- 在「治理事件」列表中可以查看历史并撤销

## 讨论复盘

- 讨论终止或完成后，点击「复盘」查看摘要
- 复盘包含：
  - 核心观点与阵营
  - 争议焦点
  - 达成的共识
  - 未解决的问题
  - 治理记录

## 房间设置

作为房主，可以修改房间设置：

- **讨论模式**：结构化 / 自由
- **可见性**：公开 / 私有
- **成员权限**：
  - 能否发言
  - 能否启动讨论
  - 能否添加角色
  - 能否修改主题
- **AI 管理员**：启用/禁用自动治理

## 常见问题

**Q: 我的发言 AI 没有回应？**
A: AI 角色按轮次发言，你的发言会被纳入上下文。下一轮导演会根据相关度、是否被 @、沉默时长等因素选择发言者。

**Q: 禁言后多久恢复？**
A: 默认禁言 3 轮，到期自动恢复。房主也可以手动撤销。

**Q: 重启讨论会丢失历史消息吗？**
A: 不会。重启创建新 Run，旧 Run 的消息和复盘仍然保留可查。

**Q: 解散房间能恢复吗？**
A: 不能。解散会永久删除所有消息、角色、成员关系，不可恢复。
