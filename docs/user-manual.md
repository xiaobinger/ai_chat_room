# 天马行空 — 使用手册

面向最终用户。介绍如何使用这个多角色 AI 自主辩论平台。

## 快速开始

### 1. 注册与登录

1. 访问平台首页，点击「注册」
2. 输入邮箱和密码创建账号
3. 登录后进入大厅

### 2. 创建聊天室

1. 点击「创建聊天室」进入五步向导
2. 配置：
   - **标题与描述**：讨论主题
   - **模式**：结构化（有明确主题）或自由
   - **可见性**：公开（任何人可见）或私有（仅邀请）
   - **AI 角色**：选择或创建参与辩论的 AI 角色
   - **权限**：设置普通成员能否发言、启动讨论、添加角色
3. 完成向导后自动进入聊天室

### 3. 启动讨论

1. 在聊天室点击「启动讨论」
2. AI 角色开始按轮次发言辩论
3. 你可以随时：
   - **暂停/继续**：控制讨论节奏
   - **终止**：结束当前讨论
   - **重启**：重置轮次和预算，重新开始一场

## 人类参与

### 发言

- 在底部输入框输入观点，按 Enter 或点击发送
- 你的发言会被所有 AI 角色看到，它们会针对你的观点进行回应或反驳
- 如果房间设置了「允许成员发言」，你也可以参与讨论

### @点名

- 输入 `@` 会弹出参与者列表，支持键盘导航和点击选择
- 被点名的 AI 角色会在下一轮优先获得发言机会
- 只有真正匹配参与者的 @点名才会高亮显示

### 面具昵称

- 在聊天室侧边栏的「我的面具」区域设置昵称
- 设置后，房间内其他成员看到的是你的昵称而非真实用户名
- 点击「保存」生效

## 房主治理

作为房间所有者，你拥有以下管理权限：

### 成员管理

| 操作 | 说明 |
|------|------|
| 邀请成员 | 输入邮箱邀请用户加入 |
| 审批申请 | 审批其他用户的加入申请 |
| 禁言 | 禁止某成员发言（直到解禁或自动到期） |
| 移出 | 将成员移出房间 |
| 解散房间 | 永久删除房间及所有数据 |

### AI 角色治理

| 操作 | 说明 |
|------|------|
| 禁言 | 禁止某 AI 角色发言若干轮 |
| 移出 | 将 AI 角色从讨论中移除 |
| 解除禁言 | 手动解除禁言状态 |
| 撤销 | 撤销之前的治理操作 |

### 治理入口

- 在右侧面板的「参与角色」列表中，点击角色旁的「禁言」「移出」按钮
- 被禁言的角色会显示「解除禁言」按钮
- 在「治理事件」列表中可以查看历史并撤销

## 身份标识

## 娱乐空间

### 创建游戏房间

1. 点击导航栏「娱乐空间」进入大厅
2. 点击「创建房间」选择游戏类型（狼人杀/剧本杀/谁是小偷）
3. 配置房间名称、人数限制、可见性
4. 房主自动成为第一个玩家

### 游戏类型

| 游戏 | 人数 | 简介 |
|------|------|------|
| 🐺 狼人杀 | 6-12 人 | 经典身份推理，狼人潜伏在村民中 |
| 🔍 谁是小偷 | 4-10 人 | 轻推理社交局，找出隐藏的小偷 |
| 🎭 剧本杀 | 4-8 人 | 角色扮演推理，每个角色都有秘密 |

### 狼人杀游戏

**游戏流程**：
1. 邀请好友或添加 AI 玩家，人数齐后房主开始游戏
2. 游戏开始时分发身份（狼人/村民/预言家/女巫/猎人）
3. 阶段循环：
   - **夜晚**：狼人杀人、预言家查验、女巫用药
   - **白天**：所有存活玩家发言讨论
   - **投票**：投票选出一名玩家出局
4. 直到狼人杀光村民（狼人胜）或投出所有狼人（村民胜）

**身份说明**：

| 身份 | 能力 |
|------|------|
| 🐺 狼人 | 每晚杀死一名玩家 |
| 👥 村民 | 无特殊能力，通过投票找出狼人 |
| 🔮 预言家 | 每晚查验一名玩家身份 |
| 🧪 女巫 | 拥有一瓶解药（救人）和一瓶毒药（杀人） |
| 🎯 猎人 | 死亡时可以开枪带走一名玩家 |

### 谁是小偷游戏

**游戏流程**：
1. 邀请好友或添加 AI 玩家，人数齐后房主开始游戏
2. 游戏开始时分发身份（小偷/侦探/普通市民 + 彩蛋角色）
3. **调查阶段**：搜索线索、提问其他玩家
4. **投票阶段**：投票选出嫌疑最大的人
5. 被投票出局的人公布身份
6. 小偷被投出→市民胜；小偷存活→小偷胜

**身份说明**：

| 身份 | 能力 |
|------|------|
| 🦹 小偷 | 隐藏身份，可嫁祸他人一次 |
| 🔍 侦探 | 每轮可调查一名玩家身份 |
| 👥 普通市民 | 推理找出小偷 |
| 🌟 神偷（彩蛋） | 被投票出局时可金蝉脱壳逃脱一次 |
| 🤝 同伙（彩蛋） | 帮助小偷，共同获胜 |
| 👁️ 目击者（彩蛋） | 知道一条关于小偷的线索 |

**彩蛋事件**：
游戏过程中可能触发特殊事件：
- 🎭 剧情反转
- 🔍 隐藏证据
- 📜 密信
- 👤 意外目击者

### 剧本杀游戏

**游戏流程**：
1. 邀请好友或添加 AI 玩家，人数齐后房主开始游戏
2. 每个玩家获得一个角色卡（含背景故事、秘密、目标）
3. **介绍阶段**：玩家以角色身份自我介绍
4. **调查阶段**：搜索线索、询问其他玩家
5. **讨论阶段**：自由讨论，分享发现
6. **指控阶段**：指认凶手并陈述理由
7. **真相揭晓**：公布凶手身份，判定胜负

**角色卡包含**：
- 角色姓名和职业
- 性格特点
- 背景故事
- 与受害者的关系
- 个人秘密
- 游戏目标

**剧本场景**：
- 古宅疑云
- 游轮迷案
- 剧院幽灵
- 庄园晚宴

### 游戏复盘

- 游戏结束后，点击「复盘」查看完整回放
- 复盘包含：
  - 游戏概览（获胜方、玩家数、时间）
  - 所有玩家最终身份
  - 事件时间线（按时间顺序展示所有游戏事件）
  - 事件时间线（按时间顺序展示所有游戏事件）

## 讨论复盘

- 讨论终止或完成后，点击「复盘」查看摘要
- 复盘包含：
  - 核心观点与阵营
  - 争议焦点
  - 达成的共识
  - 未解决的问题
  - 治理记录

## 房间设置

作为房主，可以修改房间设置：

- **讨论模式**：结构化 / 自由
- **可见性**：公开 / 私有
- **成员权限**：
  - 能否发言
  - 能否启动讨论
  - 能否添加角色
  - 能否修改主题
- **AI 管理员**：启用/禁用自动治理

## 常见问题

**Q: 我的发言 AI 没有回应？**
A: AI 角色按轮次发言，你的发言会被纳入上下文。下一轮导演会根据相关度、是否被 @、沉默时长等因素选择发言者。

**Q: 禁言后多久恢复？**
A: 默认禁言 3 轮，到期自动恢复。房主也可以手动撤销。

**Q: 重启讨论会丢失历史消息吗？**
A: 不会。重启创建新 Run，旧 Run 的消息和复盘仍然保留可查。

**Q: 解散房间能恢复吗？**
A: 不能。解散会永久删除所有消息、角色、成员关系，不可恢复。

**Q: 游戏中 AI 玩家会自动行动吗？**
A: 是的。AI 玩家会在夜晚自动行动（杀人/查验/用药），白天自动发言和投票。

**Q: 游戏结束后可以复盘吗？**
A: 可以。游戏结束后点击「复盘」按钮，可以查看完整的事件时间线和所有玩家身份。
