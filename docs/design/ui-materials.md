# 天马不行空 — UI 素材与设计系统

## 1. 设计原则
- 未来感但克制：暗色基底 + 紫色主色，避免过度游戏化。
- 清晰的信息层级：房间状态、讨论进度、角色发言、治理动作必须一眼可辨。
- 紧急控制可达：暂停、继续、终止、点名、撤销始终可见。
- 可解释的治理：每次处罚都展示规则、证据、动作和撤销入口。

## 2. 色彩系统
### 2.1 主色
- 主色：`#7457ff`
- 主色前景：`#ffffff`
- 主色阴影：`rgba(116, 87, 255, 0.22)`

### 2.2 语义色
- 成功/在线：`#5ee9a3`
- 警告/思考：`#ffc66f`
- 危险/禁言：`#ed6868`
- 信息/治理：`#9b8ce4`

### 2.3 中性色
- 背景：`#0a0b10`
- 表面：`#121319`
- 边框：`#252630`
- 次要文字：`#777986`
- 正文：`#d4d4dc`

## 3. 字体与排版
- 主字体：Manrope + Noto Sans SC
- 代码/数据字体：系统等宽字体
- 标题层级：38px / 24px / 18px / 14px
- 正文字号：13px，行高 1.75
- 辅助文字：10px–12px

## 4. 角色视觉语言
- 头像底色按角色区分：紫色、蓝色、橙色等
- 状态点：
  - idle：灰色
  - thinking：黄色
  - speaking：绿色带光晕
  - muted：红色
- 发言气泡无背景色，仅用头像色和名字标识归属

## 5. 组件规范
### 5.1 按钮
- Primary：填充主色，圆角 10px，带主色阴影
- Secondary：暗背景 + 边框，圆角 10px
- Ghost/图标按钮：透明背景，hover 时显示背景

### 5.2 卡片
- 背景：`#121319`
- 边框：`#272831`
- 圆角：14px–18px
- hover 时边框变主色，轻微上移

### 5.3 输入框
- 背景：`#0d0e13`
- 边框：`#30313b`
- 圆角：10px
- 聚焦时边框变主色

### 5.4 抽屉/面板
- 桌面端：固定右侧面板 285px
- 平板端：滑出式抽屉
- 移动端：86% 宽度，带遮罩

## 6. 布局规范
### 6.1 桌面端 1440px
- 三栏：左导航 230px / 中间消息区自适应 / 右面板 285px
- 顶部固定：房间标题和状态
- 底部固定：控制栏

### 6.2 平板端 1024px
- 左栏收缩为图标栏 80px
- 右栏改为抽屉
- 内容区保持可读

### 6.3 移动端 390px
- 单栏布局
- 顶部：房间标题 + 状态
- 中部：消息流
- 底部：固定控制栏
- 角色/规则通过顶部按钮打开抽屉

## 7. 交互状态
- 空态：引导创建或加入
- 加载中：骨架屏或 spinner
- 成功：绿色提示
- 错误：红色边框 + 错误文案
- 权限不足：隐藏按钮或置灰
- 网络断开：重连按钮 + 状态提示

## 8. 可访问性
- 所有按钮有可见文本或 aria-label
- 颜色对比度满足 WCAG AA
- 键盘可访问所有交互
- 焦点状态清晰可见
