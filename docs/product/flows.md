# 核心用户流程

## 1. 创建聊天室
**前置条件**：用户已进入大厅。

**主路径**：点击创建 → 填写名称和简介 → 选择主题讨论或自由聊天 → 添加至少一个 AI 角色 → 配置管理员与预算 → 查看启动确认 → 保存并进入聊天室。

**失败路径**：主题模式缺少主题、没有可发言角色、预算无效或角色配置冲突时停留在当前步骤，定位错误且保留已填内容。

**完成信号**：房间状态为 `draft`，聊天室显示已添加角色、规则与“启动讨论”按钮。

## 2. 定制 AI 角色
**前置条件**：用户从角色工坊或创建向导进入角色编辑器。

**主路径**：设置身份与头像 → 填写背景、性格、立场、语言风格和目标 → 设置知识边界与禁区 → 运行测试对话 → 保存角色 → 添加到当前房间。

**失败路径**：必填字段为空、规则相互冲突、测试响应失败时允许保存草稿，不将未完成角色加入正式讨论。

**完成信号**：`AgentProfile` 保存成功，房间内生成独立 `RoomAgent`，临时立场不会覆盖原模板。

## 3. 配置 AI 管理员
**前置条件**：操作者为房主，房间处于 `draft` 或 `paused`。

**主路径**：选择管理员角色 → 启用规则模板 → 新增自定义规则 → 调整偏题阈值和处罚阶梯 → 配置例外名单 → 预览动作 → 发布规则版本。

**失败路径**：规则缺少触发条件、处罚无上限、管理员试图管理自身或配置超出权限时阻止发布，并指出冲突项。

**完成信号**：生成不可变的 `ModeratorPolicy` 版本，聊天室侧栏显示规则摘要和版本号。

## 4. 发起主题辩论
**前置条件**：房间至少有一个可发言 AI；主题、目标和完成条件有效；预算可用。

**主路径**：房主点击启动 → Run 从 `draft` 进入 `queued/running` → 导演选择角色 → 角色依次思考和发言 → 角色引用、反驳或追问 → 达到完成条件或房主正常结束 → 生成复盘。

**失败路径**：模型超时重试一次；单角色失败时标记 `error` 并选择其他角色；无可用角色、预算耗尽或重复循环时转 `terminated` 并显示原因。

**完成信号**：Run 为 `completed` 或有明确原因的 `terminated`，消息顺序完整，复盘入口可用。

## 5. 自由聊天
**前置条件**：房间模式为自由聊天，至少有三个可发言角色用于完整体验。

**主路径**：房主启动 → 导演根据点名、冲突度、沉默时长和预算选择角色 → 角色可延展话题 → 用户可插话或点名 → 系统持续检测重复与成本 → 房主结束或系统达到限制。

**失败路径**：连续重复观点达到阈值时先引导换角度，仍重复则终止；无人可发言时停止并提示添加或恢复角色。

**完成信号**：至少三个角色完成接续发言，且讨论在终止条件内结束，没有无限循环。

## 6. 人工干预与治理
**前置条件**：Run 为 `running` 或 `paused`。

**主路径**：房主暂停或点名角色；管理员检测偏题或违规 → 生成规则、证据与建议动作 → 按处罚阶梯提醒、警告、禁言或移出 → 房主查看详情 → 必要时撤销禁言 → 恢复讨论。

**失败路径**：证据不足时管理员只记录建议，不执行高影响动作；状态已变化导致动作冲突时拒绝执行并刷新当前状态；管理员涉及自身时交由房主决定。

**完成信号**：每个治理动作都有 `ModerationEvent`，界面显示执行结果，撤销后角色状态正确恢复且原记录保留。

## 7. 查看讨论复盘
**前置条件**：Run 已 `completed`、`terminated` 或由房主在暂停状态下请求阶段复盘。

**主路径**：进入复盘 → 查看关键观点和阵营 → 展开争论时间线 → 查看共识、分歧和治理动作 → 点击摘要定位原消息 → 选择沿用旧主题继续或创建新主题。

**失败路径**：摘要生成失败时保留原消息与治理日志，允许重试；引用消息不可用时标记缺失，不伪造证据。

**完成信号**：摘要条目可追溯，用户可从复盘创建引用旧 Run 的新 Run。

## 跨流程一致性
- 所有流程中的 Run 状态以 `docs/product/state-machines.md` 为准。
- 所有管理操作以 `docs/product/permissions.md` 为准。
- 任何失败不得丢失已经完成的消息、治理事件或用户草稿。
- 门 A 未通过前，不创建 `prototype/` 或正式工程目录。
